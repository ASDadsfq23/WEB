Практичні роботи

  • Практична №1: Основи HTML

    Створення структури персонального сайту за стандартами HTML5 та сторінки з календарем розкладу занять.

  • Практична №2: Основи CSS

    Практична демонстрація роботи з базовими селекторами, властивостями відступів, тінями та позиціюванням.

  • Практична №3: Основи Flexbox

    Верстка адаптивної копії головної сторінки відеосервісу YouTube з використанням технології FlexBox.

  • Практична №4: Основи Grid

    Створення інтерактивної сторінки з дизайном повнорозмірної клавіатури за допомогою сітки CSS Grid.

  • Практична №5: Верстка портфоліо

    Допрацювання головної сторінки сайту відповідно до макета Figma з адаптацією блоків під навчальні роботи.

  • Практична №6: Анімація та спрайти

    Створення анімованої сцени з покемоном за допомогою покрокових CSS-спрайтів (@keyframes, steps) та руху фону.
